# Encuentra a Emi

Juego de palabras para niños y adultos. Emi corre hacia su cabaña y Jurásica lo persigue: cada letra correcta acerca a Emi, cada error acerca a Jurásica.

- **Peques:** pistas con dibujos, sin reloj.
- **Mayores:** pistas con definiciones, letras de más y reloj en contra.

Es una app web instalable (PWA) en un solo `index.html`, sin dependencias. Funciona sin internet después de la primera visita.
